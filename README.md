#### iMotion Infenion Flasher
***
JIG flasher yang digunakan untuk melakukan flash / upload firmware ke Infenion *MCU IMC101* .

**Spesifikasi :**
1. Menggunakan SBC orangepi PC.
2. Hemat daya dengan power supply 5V/2A
3. Empat channel UART dengan speed 115200 bps
4. UI dengan menggunakan monitor dengan koneksi HDMI

**Fitur :**
1. Kontrol untuk start flash dengan menggunakan 1 tombol.
2. Flash speed 80 detik.
3. Empat channel untuk 4 line.
4. update firmware target dengan menggunakan USB Flashdisk.
